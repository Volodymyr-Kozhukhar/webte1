# Zdroje

- Písmo Nunito: https://github.com/googlefonts/nunito. Lokálne súbory WOFF2 pochádzajú z Google Fonts. Licencia SIL Open Font License 1.1 je uložená v `fonts/OFL.txt`.
- Pri tvorbe HTML a CSS používam OpenAI Codex na generovanie kódu a vysvetľovanie riešenia.
- Avatar s iniciálami VK je vlastná SVG ilustrácia vytvorená pomocou OpenAI Codex.
- Obrázok virtuálneho kokpitu MiG-29: https://files.digitalcombatsimulator.com/en/files/3335443/ (DCS: MiG-29 Refurbished Clean English Cockpit Mod, používateľ Krasniye).
- Opisy prístrojov kokpitu: oficiálny manuál DCS MiG-29, https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf.
- Umiestnenie kruhov a panelov je upravené podľa dodanej ukážky `positioning-demo.zip`.
