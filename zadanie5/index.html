      POD KAPOTOU

      Malý obchod, praktický JavaScript.

      DOM · udalosti · referencie · Promise · async / await

      Ako to funguje? +

      DOM a bezpečný text. Skript používa defer. Produkty vytvára cez createElement a DocumentFragment; názvy vkladá cez textContent, takže HTML v názve sa nespustí.

      Udalosti a košík. Každé tlačidlo má svoj addEventListener. Jeho closure si pamätá konkrétny produkt. push pridáva položku, reduce počíta súčet.

      Zľava bez mutácie. map a { ...item } vytvoria nové objekty s upravenou cenou. Tlačidlo prepína stav; pôvodné ceny ostávajú rovnaké.

      Asynchrónne načítanie. Promise simuluje server, await čaká bez blokovania stránky. Server má 30 % pravdepodobnosť chyby: catch zobrazí správu a finally opäť zapne tlačidlo.
